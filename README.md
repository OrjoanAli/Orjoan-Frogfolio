# 🐸 Orjoan's Portfolio – Retro Windows & Frog Themed

🌿 Super excited to share my personal portfolio website — a little corner of the internet that reflects who I am, built with love, frogs, and a lot of green!

## 💻 Project Overview

This is my personal portfolio website designed with a **retro Windows 98 aesthetic** and a **frog theme** 🐸. Instead of a boring traditional layout, each section is represented by a cute frog folder icon that opens a retro-style popup window when clicked — because why not make it fun?

## ✨ Features

* 🐸 **Frog Folder Icons** – clickable frog-themed folder buttons for each section.
* 🪟 **Retro Popup Windows** – each section opens as a Windows 98-style dialog box.
* 🟩 **Pastel Green Grid Background** – soft aesthetic with a graph paper feel.
* 💾 **Fixed Social Bar** – LinkedIn, GitHub, CV, and Email always visible at the bottom.
* 📱 **Mobile Responsive** – works on both desktop and mobile browsers.
* ✨ **Smooth Animations** – fade in/out effects on load and interactions.
* ⌨️ **Blinking Cursor** – retro cursor effect on the PORTFOLIO title.

## 🗂️ Sections

* 👤 **Profile** – about me, my role, and a personal quote.
* 🌐 **Works** – my projects with GitHub links.
* 🏆 **Volunteering Journey** – Linux Society, IEEE Computer Society, Hult Prize.
* 📄 **Skills** – my technical and professional skills.

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
